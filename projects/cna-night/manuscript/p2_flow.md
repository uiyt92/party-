# 밤에서 해야 할 것 — 전체 플로우

앞에서 밤에서 중요한 것(몸·페르소나·부담)을 봤다.\
이제 그걸 들고 실제로 뭘 하느냐다.

밤게임은 진입부터 관계, 그 이후까지 하나의 흐름으로 이어진다.\
세부로 들어가기 전에 큰 그림부터 잡자.

[[DIAGRAM:roadmap]]

## 흐름은 다섯 칸이다

**1.\
진입** — 어디서 만나느냐.\
클럽·라운지·헌팅포차·술자리·밤거리.\
환경마다 규칙이 다르다.\
공통은 상황 포착 → 선해소 → 짧은 제안.

**2.\
대화** — 무슨 말을 하느냐.\
멘트는 외우는 게 아니라 상황에서 만든다.\
가치 → 관심 → 여유 → 반응 확인 → 제안 루프로 굴린다.

**3.\
에스컬레이션** — 키스, 시간·장소 각 재기.\
텐션을 올렸다 낮췄다 하며 온도를 쌓는다.

**4.\
관계** — 밀 때와 멈출 때.\
초록·노란·빨간불 신호를 읽는다. **이게 이 책에서 가장 중요하다.**

**5.\
이후** — 선택 후 불안 방지, 애프터로 이어가기, 필터링.

각 칸은 다음 장부터 하나씩 상세히 뜯는다.

## 직선이 아니라 변수 위의 흐름이다

이 다섯 칸은 깔끔한 직선이 아니다.\
중간에 친구가 끼고, 경계가 오르고, 시간이 늦는다.

이런 변수를 터지기 전에 미리 낮추는 게 선해소다.\
그래서 진입 다음에 바로 '변수 대응'을 다룬다.

그리고 흐름 전체를 관통하는 원칙 하나. **밀 때와 멈출 때를 아는 것.** 초록불이면 나아가고, 빨간불이면 멈춘다.\
이걸 못 지키면 나머지 기술은 다 무의미하다.

> **핵심**: 진입 → 대화 → 에스컬레이션 → 관계 → 이후. 직선이 아니라 변수 위의 흐름이고, 언제나 신호 위에서 움직인다.

자, 첫 칸부터.\
밤엔 어디서 만나느냐가 먼저다.
