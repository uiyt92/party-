# 도식 설계 명세

각 챕터 본문의 `<!-- 도식: ... -->` 지시자에 대응하는 도식의 설계안이다.
빌드 단계(Typst 매크로 또는 HTML 슬라이드 컴포넌트)에서 이 명세대로 렌더링한다.
디자인 토큰은 기존 '답장의 기술' 시스템 계승: 블루 `#2563eb`, 네이비 `#1e3a8a`,
보라 `#7c3aed`(심리), 레드 `#dc2626`(경고/빨간불), 그린 계열(초록불), Pretendard + Noto Serif KR.

---

## 1. `pickup_split` — 데이 게임 vs 나이트 게임 분기도  (01_frame.md)
- **형태**: 상단 '같은 상대, 두 갈래'에서 두 갈래로 분기하는 다이어그램.
- **좌 트랙(데이 게임·낮의 방식)**: 목표=계속 만나고 싶게, 방식=천천히 신뢰·호감, 결과=다음 약속. (무채색/그레이)
- **우 트랙(나이트 게임·밤의 방식)**: 목표=그 밤에 끌리게, 방식=텐션·감정·몸, 결과=그날 관계. (레드 강조)
- **메시지**: 두 방식은 목표·규칙·판단 기준이 다르다. 이 책은 나이트 게임(우 트랙)을 다룬다.

## 2. `tension_curve` — 텐션 곡선  (02_state.md)
- **형태**: 가로축=시간, 세로축=텐션. 올림/낮춤을 반복하며 전체적으로 우상향하는 파도형 곡선.
- **대비 요소**: 평평한 직선(초보의 오해 "계속 높게")을 흐린 점선으로 겹쳐 대비.
- **메시지**: 텐션은 유지가 아니라 흔드는 것. 낙차가 긴장을 만든다.

## 3. `brain_model` — 좌뇌 vs 우뇌 커뮤니케이션  (02_state.md)
- **형태**: 2열 대비표 카드. 같은 상황("요즘 좀 춥다")에 대한 두 반응.
- **좌뇌(레드/무채색)**: "작년보단 덜 추운데?" → 맥 끊김.
- **우뇌(블루)**: "맞아 패딩 하나 사야겠어 ㅋㅋ" → 이어짐.
- **메시지**: 논리로 이기면 감정은 식는다. 감정을 같이 타라.

## 4. `mirror_mask` — 거울 효과  (03_mask.md)
- **형태**: 좌우 대칭 인물 아이콘. 남자가 쓴 가면 → 여자가 꺼내는 가면.
- **위 행(불리)**: 남=착한/반듯 → 여=단정/방어(아껴야 할 사람). (무채색)
- **아래 행(유리)**: 남=솔직/야함 → 여=개방/편안. (블루)
- **메시지**: 상대는 내 가면을 따라 쓴다.

## 5. `level_curve` — 레벨업 곡선  (03_mask.md)
- **형태**: 가로축=애프터 경험치(횟수), 두 곡선. '긴장'은 우하향, '여유'는 우상향, 중간 교차점.
- **메시지**: 경험이 쌓이면 긴장은 내려가고 여유(=매력)는 올라간다. 오늘은 경험치 쌓는 날.

## 6. `timeline_funnel` — 실전 타임라인 퍼널  (04_flow_meet.md)
- **형태**: 뒤로 갈수록 좁아지는 가로 퍼널. 7단계: 만남 → 술집 이동 → 자리·초반 대화 →
  감정·스토리 → 키스 → 장소 이동 → 관계.
- **각 칸 라벨**: 단계별 핵심 목표 한 줄(예: 만남="텐션 넣고 반겨주기", 장소 이동="초록불 확인").
- **메시지**: 오늘 하루의 전체 지도. 지금 어디쯤인지 안다.
- **주의**: '장소 이동' 칸에 초록불 아이콘을 달아 8장(신호 판단)과 연결.

## 7. `ioi_mix` — IOI × FAKE IOI 배합  (04_flow_meet.md)
- **형태**: 2x2 매트릭스. 가로축=말(칭찬↔무관심), 세로축=표정(반함↔무심).
- **강조 분면**: '말은 칭찬 + 표정은 무심' 분면을 스윗스팟으로 블루 하이라이트.
- **메시지**: 초반 호감은 말로만, 표정은 무심하게. 온도차가 세련된 호감.

## 8. `talk_ratio` — 대화 비율 스택 바  (05_flow_talk.md)
- **형태**: 초반/중반/후반 3구간 누적 막대. 각 막대에 친구·연애·섹스 대화 비율.
- **변화**: 후반으로 갈수록 섹스(블루) 비중이 커지고 친구·연애는 줄어듦.
- **메시지**: 초반은 친구·연애로 풀고, 중반부터 섹스 비율을 올린다.

## 9. `story_structure` — 성적개방화 5단계 구조도  (06_storytelling.md)
- **형태**: 5칸 가로 스텝. ①운 띄우기 ②DHV ③솔직함 미화 ④원나잇 정상화 ⑤수위 키워드→ASD 완화.
- **2층 구성**: 각 칸 위=겉으로 하는 말, 아래=속에 심는 메시지.
- **메시지**: 겉은 옛 연애 회상, 속은 다섯 장치. 뼈대만 가져가고 살은 내 얘기로.

## 10. `consent_flow` — 합의 신호 판별 플로우차트  (08_consent.md) **[핵심 도식]**
- **형태**: 세로 플로우차트. 시작="장소 이동 제안" → 상대 반응 분기.
- **초록불(그린)**: 몸이 따라옴·눈 안 피함·스스로 다음 스텝 → **밀어도 됨**.
- **노란불(옐로)**: 말은 튕기는데 몸은 남고 웃음 → **멈추고 텐션 낮춰, 스스로 오게**. →
  재확인 후에도 안 오면 빨간불로 내려가는 화살표.
- **빨간불(레드)**: 몸을 뺌·정색·반복 거절·"강제 아니냐" → **즉시 중단·집 보내줌**.
- **하단 고정 문구**: "애매하면 언제나 '멈춤'이 기본값." 오른쪽 출구는 셋뿐 —
  밀거나 / 기다리거나 / 끝내거나. **'밀어붙여라'는 없다.**
- **메시지**: 밀 때·기다릴 때·멈출 때를 신호로 판단. 몸의 반응은 동의가 아니다.

## 11. `filter_funnel` — 필터링 깔때기  (09_after.md)
- **형태**: 세로 깔때기. 다수의 번호 → 폰게임 단계(섹슈얼 코드로 반응 확인) → 개방적 성향만 애프터로.
- **메시지**: 시간 낭비를 앞단(폰게임)에서 줄인다. 단, 초보는 일단 다 만나 경험치부터.

## 참고
- 카톡 대화 목업이 필요한 지점은 기존 `.kt` 클래스 재사용. 원문 PDF의 카톡 캡처는
  저작권상 재사용하지 않고, 필요 시 새 목업 생성(`phone-mockup` 스킬) 또는 텍스트 블록으로 대체.
- 도식 키 대응표: 지시자 `<!-- 도식: 설명 -->`은 본문에 서술형으로 넣었고, 위 명세가
  각 지시자의 렌더 설계다. Typst/HTML 빌드 시 이 문서를 참조.
