# 『답장의 기술』 150p 확장 기획안

> 현재 ~72p(21섹션, ~71,000자) → **목표 150p+ (상한 없음 — 넘어도 됨)**, "패딩 없이 질 높게" 확장.
> 작성 기준: 마크다운 원문 21섹션 전수 감사 + 레퍼런스 3종(카톡101·테레사·New폰게임) 상황 마이닝(원시 403 → 정제 168 상황).
> **확정 결정(2026-06-13):** ① 레퍼런스 168개 상황 **전부 포함**(섹톡·성적 진입·차단 우회 계열 포함) ② 페이지 상한 없음 → 168개 상황을 폭넓게 소화해 **~170~190p**까지 확장.

---

## 1. 확장 3원칙

1. **분량≠희석.** 추상 산문을 늘리지 않는다. 늘어나는 건 **실전 카톡 로그·케이스·도식·자가진단**뿐.
2. **표절 0.** 레퍼런스에서 가져오는 건 **상황 유형·트리거·심리 메커니즘**뿐. 대사·카톡 스크립트는 **100% 신규 생성**.
3. **중복 정리 선행.** 늘리기 전에 겹치는 3쌍의 경계를 가른다(아래 §3).

## 3. 중복 정리 방침 (확장 전 선행)

| 쌍 | 역할 재정의 |
|---|---|
| 02 ↔ 07 | **02 = 마인드/원리** (조급함이 왜 독인가) · **07 = 대기 행동 매뉴얼** (며칠 뒤 어떤 멘트로 재접근) |
| 04 ↔ 05 | **04 = 설득(짧게 압축)** · **05 = 실전 공식·예시** (목표 논지 반복 제거) |
| 11 ↔ 12 | **11 = 실전 멘트 모음** (장난·리액션·안전지대) · **12 = 원리+조합** (4원리 통합 로그·멘트 뱅크) |

→ 삭제가 아니라 **상호참조 라벨**로 묶어 "반복"이 아닌 "다각도 학습"으로 읽히게 한다.

## 4. 표절 회피 방법론 (핵심)

```
레퍼런스(카톡101·테레사)  ──[상황 유형·트리거·심리만 추출]──►  상황 taxonomy(168개)
                                                                      │
                              ┌───────────────────────────────────────┘
                              ▼
            상황별 분류 → 각 상황에 맞는 카톡 스크립트 100% 신규 생성
                              │
                              ▼
            집필 후 표절 스캔: 레퍼런스 원문과 문장 1:1 일치 0건 검증 + humanize 패스
```

- 가져오는 것: "프사로 직업 유추", "단답 6단계 대응", "식사 funnel" 같은 **상황 라벨·심리**.
- 절대 안 가져오는 것: 레퍼런스의 **실제 대사 한 줄**. 모든 인물명·멘트·대화 흐름은 새로 만든다(기존 책처럼 "민지" 등 자체 캐릭터).

## 5. 톤·구성 — 전부 포함 + 3-Part 그라데이션

**결정: 168개 상황 전부 포함** (섹톡·성적 진입·차단 우회 포함). 단, 깨끗한 앞부분과 수위 높은 뒷부분을 **Part로 분리**해 독자가 스스로 깊이를 선택하게 한다.

| Part | 성격 | 범위 |
|---|---|---|
| **Part 1 — 대화를 여는 법** | 클린 | 마인드·프사·첫톡·읽씹·대화 잇기 (기존) |
| **Part 2 — 키우고 만나는 법** | 클린 | 화술·호감신호·말놓기·통화·만남 (기존) |
| **Part 3 — 긴장과 수위 (심화·19금)** | 어덜트 | 섹톡 진입 사다리·중의성·만나기 전 합의·차단/잠수 심화·멘탈·다중관리 (신규) |

- **Part 3 진입부에 성숙도 고지** 1p — "여기부터는 성인·고수위 내용. 동의·존중·합법 범위 전제" 명시(법적·윤리 안전장치 + 톤 전환).
- Part 1·2만 읽어도 "호감→만남"은 완결. Part 3는 원하는 독자만.
- **윤리 가드레일**: 차단 우회·잠수 대응도 "집착·스토킹이 아니라 깔끔한 판단·손절"의 틀로 서술. 상대 동의·존중을 일관되게 명시.

## 8. 신규 콘텐츠 상세

### 8-A. 20_cases 신규 통합사례 15개 (대사는 집필 시 신규 생성)

기존 10개와 겹치지 않는 신규 상황 우선, 단계별 분산:

1. 앞서나가기 호칭 드립 풀세트(장모/펫네임) — 호감신호
2. 하소연에 챙김 리액션(정보형→감정형) — 대화유지
3. 식사 funnel 풀플로우(취향→명분→확정) — 약속
4. 빈말 만남을 진짜 약속으로(밀당→클로징) — 약속
5. 규칙적 연락→루틴 깨기 빈자리 효과 — 읽씹
6. 차인 듯한 단답 6단계 대응 풀케이스 — 대화유지
7. 명절·프사업뎃 명분 죽은번호 부활 — 부활
8. 슬로우핑(오래 끊긴 번호 가볍게 재점화) — 부활
9. 친구존 탈출 — 남녀 프레임 심기 — 말놓기
10. 다중 연락 분산으로 평정심 회복 — 마인드
11. 사진 배경 미끼로 다음 만남 빌드업 — 사진
12. 거절 후 재만남(소프트 커피 제안) — 약속
13. 인스타 아이디·피드로 첫 대화 트기 — 첫톡
14. 키워드 잡기로 끊긴 대화 살리기 — 대화유지
15. 실패→복구 before/after(반면교사+교정본) — 종합

### 8-B. 15_situation 트리거형 상황 15개

"상대가 X하면 → 어떤 프레임/기술" 구조 (건강한 것만):

프사 바꿈 / 음식 사진 / 셀카 평가 요청 / 가족과 있음 / 다른 사람 호감 표함(가벼운 질투) / 인스타 아이디 공유 / 요리·재능 언급 / 피곤·푸념(챙김) / 자취·혼자 삶 / 단답·기계적 답(NPC 드립) / "오늘 뭐했어"(브리핑 놀이) / 명절·연말 명분 / 프로필 글귀·스펙 / 동의만 하고 약속 회피 / 핫플·맛집 인증

### 8-C. 신규장 "답장을 받았다면" (제목 직결 공백)

- 단답 6단계 운영(힘빼기→화제선점→궁금증→티키타카→호감→유지)
- 정보형↔감정형 균형, 받아칠 포인트 흘리지 않기, 에너지 미러링
- 핵심: 5~10턴 풀 로그 3개 + 각 턴 "여기서 흔한 실수" 박스

## 9. 포맷 표준 (전 장 통일 컴포넌트)

1. **연속 카톡 로그** — 기존 chat/me/her 컴포넌트로 5~10턴, 줄별 주석 라벨
2. **첨삭 코너(Before→After)** — 독자가 보낼 법한 톡 BAD → 교정 GOOD
3. **자가진단/워크시트** — 점수표·체크리스트(13·16·21에 도입 후 확산)
4. **심리 박스(💡 왜 통할까)** — 15·16·20에도 통일 적용
5. **CSS 도식** — `<!-- 도식 -->` 마킹만 있는 곳(08·09·11·12·15) flow/step/cause-card로 실구현

## 10. 실행 Phase

- **Phase 1 (클린 핵심, ~110p):** 신규장 "이어가기" + 20_cases 15케이스 + 15_situation 15상황 + 전장 연속로그 → 검수·승인
- **Phase 2 (클린 보강, ~150p):** 부록 종합 + 11/12 재편 + 13 도구화 + 소형 보강(03·06·07·16·19)
- **Phase 3 (Part 3 심화, ~180p):** 성숙도 고지 + 심화 5개장(섹톡 입문 / 수위 사다리 / 만남 전 합의 / 차단·잠수 심화 / 멘탈·다중관리)
- **Phase 4 (정합·검증):** Part 분권·번호·브리지 정합, humanize 패스(산문만), **표절 스캔**, Typst 빌드(도식·박스·19금 표시 점검), 페이지수 확인

각 Phase는 카톡 스크립트 신규 생성 → 표절 대조 → 사용자 확인 순. 168개 상황 전부를 단계별로 소화(클린은 Part 1·2, 수위는 Part 3).

## 11. 검증 기준

- 신규/수정 산문 humanize 등급 **A/B**
- 레퍼런스 원문과 **문장 1:1 일치 0건** (표절 스캔)
- 중복 3쌍 경계 정리 완료(같은 예시 한 곳에만)
- Typst 빌드 성공 + 도식·표 깨짐 0 + **~150p** 도달
- `(N장)` 상호참조가 신규 번호와 일치
