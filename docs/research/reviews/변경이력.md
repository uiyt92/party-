## 7. UI · 진행 표시 추가

- **상단 진행 프로그레스 바** — 현재 위치/전체 비율만큼 채워지는 얇은 바(파랑→보라 그라디언트, 화면 최상단 고정). 슬라이드 이동 시 `show()`에서 `(현재+1)/전체`로 갱신.
- **페이지 카운터** — `현재 / 전체`(예: 66 / 133)를 우측 **상단**에 진한 pill(어두운 배경 + 흰/하늘색 글자)로 배치. 흰 슬라이드·어두운 여백 어디서나 보이도록. (하단 배치는 프레젠테이션 시 흰 배경 위 저대비·패널 하단 클리핑으로 안 보여 상단으로 이동.)
- 슬라이드 캔버스(1280×720) 바깥 stage에 고정이라 본문 레이아웃·720px 규칙에 영향 없음.

## 8. 직관성 개선 (intuition-check 반영)

- **커리큘럼(#3) 재구성** — 4열 항목의 긴 "·" 꼬리 제거 → "주제 + 숫자 후크"만(예: `대화 운영 · 놀거리 9종`, `수위 사다리 · 5단계`). 리스트 폰트 12.5→14px, 굵은 주제 13→15px. 20개 항목 전부 1줄로 정리(기존 3~4줄 줄바꿈 벽 해소), 720 유지.
- **어휘 5개 쉬운 말로** — 디폴트→기본값 / 콜드리딩→슬쩍 넘겨짚기 / 중의성→두 갈래 뜻 / 비독점 단계→아직 서로 안 정한 사이 / "예제를 통해"→"예제로". (메타인지는 본문에 이미 풀이돼 있어 유지.)
