## A. 정합성 (슬라이드 ↔ 책) — 2건 ★최우선
최근 슬라이드에서 다중관리 멘탈을 초반으로 옮긴 게 **책에 미반영**.

- **[med] 여유/다중관리 프레임 위치 불일치.** 슬라이드는 「여유는 숫자에서 나온다 + 3~4명 비교표」를 기본편 1강 마인드셋으로 옮겼는데, 책은 이 블록을 심화편 「흔들리지 않는 멘탈과 다중 관리」(`build_part3.typ:1528~1604`)에만 둠. 게다가 기본편은 여유를 **"상황에서 나온다"**(`build.typ:120`), 심화편은 **"숫자에서 나온다"**(`:1603`)로 달리 설명 → 한 책 안에서 문구 충돌.
  → **조치**: 기본편 마인드셋에 다중관리 프레임(숫자·비교표·"셋에 나눠 걸어라") 이동/추가, 심화편 중복은 축약 또는 "기본편 참조"로 처리, "상황/숫자" 문구 통일.
- **[low] 슬라이드 커리큘럼 개요**가 '멘탈·다중 관리'를 여전히 3부 항목으로 광고(`슬라이드:247`)하는데 실제 강의는 1부로 이동됨 → 목차와 실제 흐름 불일치.

## B. 렌더 깨짐 (정확성) — 즉시 수정 권장
- **[med] 이스케이프 안 된 물결 `~`** — Typst에서 `~`는 물결이 아니라 nbsp로 렌더돼 **데이터가 깨진다**.
  - 기본편: 범위표기 `0~1개`→`0 1개`, `1시간 반~2시간`, `5~6턴`, `0 ~ +5` 등 (703·2550·3691~3700·4133행) + 대화체 물결 다수.
  - 심화편: `(3~4명)`→`(3 4명)`(1584행), 채팅 끝맺음 `~`(429·466·489·543·813행).
  - → **조치**: 리터럴 물결은 `\~`로, 숫자 범위는 하이픈(-)/en대시(–)로 치환. (저자가 `build.typ:1928`·`build_part3.typ:254`에선 이미 `\~`로 맞게 씀 → 나머지 누락)
- **[med] 이모지 렌더 위험** — 본문 폰트(Pretendard/Noto Serif KR)에 컬러 이모지 글리프 없음, fallback 미지정.
  - 기본편 `✨`(199)·`😏`(2947)·`💡`(4985), 심화편 `🟢🟡🔴`(389·391은 텍스트 라벨 없이 이모지만)·`💡`.
  - **template `book.typ:120`의 psych-box 헤더 `💡 왜 통할까`가 책 전체 심리박스마다 반복** → 실패 시 광범위 노출.
  - → **조치**: 실제 PDF 렌더로 표시 확인. 안 뜨면 `💡→TIP`, `✨·😏` 삭제, 신호등은 '초록/노랑/빨강' 텍스트 병기, 또는 이모지 fallback 폰트 지정.
- **[med] 유령 인용** — 고양이 사진 '핵심' 콜아웃(`build.typ:1880`)이 인용한 **"무릎냥이 아니면 도도파?"는 실제 대화에 없음** (대화는 "부르면 오는 스타일이에요 아니면 도도한 편?"). + 콜아웃에 4항목 인라인 대시로 과밀.
  - → **조치**: 인용을 실제 대사와 일치, 콜아웃은 1~2문장으로 압축(또는 `*포인트*` 평문으로).

## C. 교차참조·브릿지 오류 — 4건
장 3개(질문의 사다리·카톡 말투·상대 유형별 대응)를 삽입한 뒤 참조·전환이 어긋남.

- **[med] 'N장' 번호 참조 체계 붕괴.** 삽입된 3개 장이 번호에 미반영 → '답장 받았다면' 이후 모든 참조가 1~3장 앞을 가리킴(예: '만남으로'는 실제 23번째 장인데 "20장"으로 지칭). **게다가 template에 heading numbering이 안 켜져 있어 PDF에 장 번호가 아예 안 찍힘** → 숫자 참조를 독자가 찾을 수 없음. 부록 인덱스 표에도 3개 장 누락.
  - → **조치**: 숫자 대신 **장 제목으로 참조** 통일(권장) 또는 numbering 켜고 전수 재계산 + 인덱스에 3장 추가.
- **[med] 브릿지 오예고 (기본편 `:2642`)**: 호감신호 장 끝이 "다음 장에서 '말 놓기'"라 예고하지만 실제 다음 장은 '상대 유형별 대응'.
- **[low] 브릿지 오예고 (기본편 `:1236`)**: 읽씹 장 끝이 '대화 끊김'을 예고하지만 다음 장은 '질문의 사다리'.
- **[med] 브릿지 오예고 (심화편 `:498`)**: "다음 장에서 오프라인으로 옮기는 법" 예고인데 다음 장은 '수위는 사다리처럼'(여전히 온라인). 오프라인은 한참 뒤.

## D. 중복 축약 (심화편) — 5건
집필 원칙 '중복 금지'와 충돌하는 반복.

- **[med] "섹톡은 야한 말이 아니라 온도"** 9회 반복 (들어가며 한 챕터에서만 5회).
- **[med] "만남이 먼저다" + BAD/GOOD 예시 판박이** — 시그니처 대사 "이런 얘긴 톡으로 하긴 아깝다…다음에 만나서"가 `:78`·`:763` 거의 동일 중복.
- **[med] 챕터 오프너 "나 또한 그러던 시절이 있었다"** 7~8개 챕터 동일 시작 (전체 정형 도입 ~39회).
- **[low] 들어가며 오해3가지 절 ↔ '어른의 대화'/'기본편 충분' 절** 같은 메시지 재서술.
- **[low] 손절 메시지 2절 중복**(`:1607`↔`:1695`) / **경구 반복** ("멈출 줄 아는 사람만이…" 4회, "밀어붙여 이긴 X 없다" 2회).

## E. 톤·밀도 (AI 티) — 편집 다듬기
- **[low] '핵심' 콜아웃이 'X가 아니라 Y다' / 'X말고 Y해라' 공식 반복** — 누적되면 과한 대구(AI 티). '아니라' 기본편 98회. → 일부를 비유·질문·행동지시로 변주.
- **[low] 상황별 대응 장(15장) 박스 과밀** — 절마다 psych-box+callout 반복 → 절당 박스 최대 2개로.
- **[low] psych-box 헤더 오용** — '💡 왜 통할까'(기법이 왜 통하나)가 **동의 경고 박스**(`:1294` "정색만 안 하면 동의? 정반대다")·자책완화 박스에도 붙음 → 경고/원칙은 `#callout`으로 분리.
- **[low] 산문에 대본 약칭 '여: 일단 만나서' 노출**(`:856`) → "상대의 '일단 만나서 얘기해요'는…"으로.
- **[low] placeholder 이름 '예린' 상충 배경**(클라이밍장/소개팅) 재사용.

## F. 동의 척추 — 1건 (문구 보강)
- **[med] '부끄… 판 깔아준다' 재프레이밍** (`build_part3.typ:277`). 여성의 부끄러움을 '은근한 동의'로 읽는 일반화가, 다른 장(머뭇거림·얼버무림=멈춤 신호, `:101`·`:663`·`:1295`)과 긴장. 바로 뒤 '안 받아주면 그냥 농담' 출구가 완화하지만 신호 해석이 엇갈림.
  - → **조치**: 같은 문단에 **"단, 부끄러워하거나 얼버무리면 그건 그린라이트가 아니라 멈춤·보류 신호"** 한 줄 명시해 다른 장과 정합.
