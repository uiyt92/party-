## 빌드 명령

**Road To Motel** (프로젝트 루트에서):
```bash
typst compile Road_To_Motel/build.typ output/Road_To_Motel.pdf --root .
```

**카톡의 정석** (구 답장의 기술):
```bash
typst compile build.typ output/카톡의정석.pdf          # 기본편
typst compile build_part3.typ output/카톡의정석_심화편.pdf   # 심화편(19금)
typst compile lead_magnet.typ output/카톡의정석_요약본.pdf   # 리드 마그넷(무료 요약본, ~20p, 강의/코칭 CTA)
```

- Typst 0.14.x. 폰트: Pretendard(본문·헤비 헤드라인), Noto Serif KR(명조), 설치돼 있음.
- 마크다운은 `@preview/cmarker`로 직접 렌더(`#cmarker.render(read("...md"))`).
- variable-font 경고는 무해(무시).

### 마크다운 작성 규칙 (공통)
- `# 섹션제목`(h1, 새 페이지) > `## 소제목`(h2) > 본문 + `**굵게**`.
- 도식 삽입점: `<!-- 도식: 설명 -->`, 심리 근거: `> **💡 왜 통할까**` 박스.
- 강조 박스: `> **핵심**: ...`, `> **BAD/GOOD**`, 카톡 대화: `> 나: / > 여:`.
- **주의(cmarker 버그)**: `**"인용"**조사` 처럼 볼드 닫는 `**`가 인용부호와 한글 조사
  사이에 끼면 렌더 실패. 조사를 볼드 안에 넣을 것 → `**"인용"조사**` 또는 `**"인용"조사** `.
- 가독성: 본문 한 문단 = 1~3문장. 긴 문단은 빈 줄로 분할.

## ══ 세미나 트랙 (라이브 강의) — 교재와 분리 관리 ══

교재(PDF/문서)와 별개로, **라이브 세미나/강의 세션**은 이 섹션에서 따로 관리한다.
교재는 "읽는 것", 세미나는 "말로 전달하고 실습하는 것"으로 목적·구성이 다르다.

### 원칙
- 세미나 커리큘럼은 교재 Part 구조를 **모듈로 재편**하되, 교재를 그대로 낭독하지 않는다.
- 세미나 = 시연 + 실습 + Q&A 중심. 교재 = 레퍼런스/복습용.
- 세미나 슬라이드는 HTML(1280×720) 라인으로 별도 산출(답장의 기술 슬라이드 방식 참고).

### Road To Motel 세미나 모듈 매핑 (교재 → 세션)
| 세션 | 교재 근거 | 세미나 초점(라이브) |
|---|---|---|
| 0. 마인드 세팅 | Part 0 프레임 | 연애/섹스 게임 분리 · 확률 게임 마인드 |
| 1. 상태 만들기 | Part 1 텐션·가면 | 텐션 실습 · 우뇌 대화 롤플레이 |
| 2. 만남~술자리 | Part 2 흐름 | 반겨주기·IOI 시연 · 상황별 리프레이밍 |
| 3. 감정·스토리 | Part 3 성적개방화 | 성적개방화 각자 대본 만들기(실습) |
| 4. 에스컬레이션·합의 | Part 4 키스·신호판별 | **신호 판별 집중 훈련**(초록/노랑/빨강) |
| 5. 이후·필터링 | Part 5 | 폰게임 필터링 · 사후 관리 |

> 세미나는 **합의(신호 판별)** 세션을 가장 비중 있게 다룬다 — 교재의 핵심 재설계 지점.

### 세미나 산출물 (예정/관리 위치)
- 슬라이드 HTML: `output/RTM_세미나_슬라이드.html` (미제작)
- 실습 워크시트: `output/RTM_워크북.html` (미제작)
- (제작 시 답장의 기술 슬라이드/워크북 템플릿 재사용)
