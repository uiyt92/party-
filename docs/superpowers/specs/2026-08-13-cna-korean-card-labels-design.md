# CNA 교재 장치 한글화 명세

## 목표

책에서 반복하는 네 가지 실전 교재 장치의 영어 표기를 자연스러운 한국어로 통일한다. 프롤로그의 안내 문구와 이후 장의 표·대화 예시·카드 제목이 서로 같은 명칭을 사용해야 한다.

## 확정 명칭

| 기존 표기 | 바꿀 표기 |
| --- | --- |
| `BAD MOVE` | `잘못된 선택` |
| `BETTER MOVE` | `좋은 선택` |
| `SCRIPT` | `대화 예시` |
| `MISSION` | `실전 과제` |

`좋은 선택`은 모든 상황에 통하는 정답이라는 뜻으로 쓰지 않는다. 같은 상황에서 상대의 부담을 줄이고 반응을 살피기 좋은 선택지라는 기존 설명을 유지한다.

## 변경 범위

- `00-prologue.md`: 네 장치의 소개 문구를 확정 명칭으로 바꾼다.
- `01-environment.md`: 비교표 머리글과 대화 예시 표기를 바꾼다.
- `03-rapport.md`: 대화 예시 표기를 바꾼다.
- `05-number-exchange.md`: 번호가 붙은 다섯 개의 대화 예시 표기를 바꾼다.
- `theme.typ`: 잘못된 선택, 좋은 선택, 실전 과제 카드의 화면 표기를 바꾼다.
- `tests/test_cna_party_project.py`: 영어 표기에 의존하는 계약을 새 한국어 명칭으로 갱신한다.

## 보존할 것

- 사용자가 직접 수정한 프롤로그 제목과 문장은 그대로 보존한다. 네 교재 장치가 들어간 문장만 필요한 만큼 고친다.
- Markdown 토큰인 `[[CALLOUT:bad|...]]`, `[[CALLOUT:better|...]]`, `[[CALLOUT:mission|...]]`은 내부 조판 규약이므로 변경하지 않는다.
- `CNA`는 책의 고유명으로 유지한다.
- 각 장의 내용, 순서, 안전 원칙, PDF 디자인은 바꾸지 않는다.
- 과거 작업 과정을 기록한 설계·계획 문서의 영어 명칭은 역사적 기록이므로 소급 수정하지 않는다.

## 조판 원칙

- 한국어 카드 제목은 기존 카드의 너비와 강조 체계 안에서 온전히 보여야 한다.
- 제목이 잘리거나 본문과 겹치면 글자 크기를 무리하게 줄이지 않고 카드 안쪽 여백이나 자간을 한국어에 맞게 조정한다.
- 표 머리글과 번호가 붙은 대화 예시에서 줄바꿈이 어색하지 않아야 한다.

## 검증

- 활성 원고와 `theme.typ`에서 네 영어 표기가 더 이상 검색되지 않아야 한다.
- 새 한국어 표기가 필요한 위치에 모두 존재해야 한다.
- 원고·조판 계약 검사와 전체 테스트가 통과해야 한다.
- PDF를 다시 빌드했을 때 허용 범위인 30~45쪽을 유지해야 한다.
- 관련 카드와 표가 있는 대표 페이지를 렌더링해 잘림, 겹침, 깨진 글자, 영어 표기 잔존 여부를 확인한다.

## 완료 기준

- 독자는 프롤로그에서 배운 네 명칭을 본문에서도 그대로 만난다.
- 배포 PDF의 교재 장치에 `BAD MOVE`, `BETTER MOVE`, `SCRIPT`, `MISSION`이 남지 않는다.
- 사용자 편집 내용과 범위 밖 파일에는 의도하지 않은 변경이 없다.
